# CRT Demonstration Guide (≈10 min)
1. **Landing page** – explain the three roles.
2. **Register** a new student (show password validation), then log in as the seeded student.
3. **Profile** – fill CGPA 7.8, branch CSE, year 2027, skills SQL, Excel, Python.
4. **Drives → Check eligibility** – show ✅/❌ reasons; Apply; try Apply again (duplicate blocked).
5. **Dashboard** – readiness breakdown, recommendation with matching/missing skills, application timeline.
6. **Resume** – upload a PDF; show checks and the honest "text analysis not performed" note.
7. **Roadmap, Interview Prep (answer one question), Compare (select 2+ drives), Calendar.**
8. Log in as **recruiter** – post a drive, filter applicants, shortlist, schedule interview, export CSV.
9. Back as student – notification bell shows unread items; mark as read.
10. Log in as **admin** – analytics and charts; open Reports and export CSV.
Tip: seed data is small – create a second student/drive beforehand so charts have content.
